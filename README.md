# 江南文笔 · 写作风格引擎

> 把《龙族》《九州缥缈录》《此间的少年》《上海堡垒》作者**江南**落在纸上的文字技法，蒸馏成一套可加载的写作风格 Skill。输入一个场景或素材，输出一段有"江南味"的文字。

---

## 1. 项目解决什么问题

**你让 AI 模仿某位作家的文笔时，常见的失败是"学形不学神"**：模型只会堆砌漂亮比喻和金句，写出来"华丽但没灵魂"，甚至分不清哪些话该让角色说、哪些该让叙述者说，一煽情就翻车。

本项目把江南的文笔从"一句模糊的感觉"（"就是很有画面感、很中二"）变成**一套可执行的文字配方**，解决三个具体问题：

1. **"江南味"不可言说 → 可执行**：把"写得像江南"拆成可操作的句法节奏、意象容器、修辞纪律，而非玄学。
2. **模仿易劣化 → 有防破功机制**：内置金句归属判据、禁止嚎啕大哭、防"文青癌"等硬规则，避免产出"只有金句没有故事"的廉价煽情。
3. **素材依赖玄学记忆 → 有据可依**：文笔 DNA 全部来自对真实原文节选（`references/research/`）的提炼，区分一手原文与观察概括、标注置信度，不是凭空捏造的风格。

**一句话**：让任何人都能稳定写出"像江南、却又是全新原创"的文字——要热血燃点、致郁感伤、物是人非、少年孤独的质感时，用它对。

## 2. 主要功能

一份**供写作模型加载的文笔 DNA**（不是观点、不是人生哲学），核心功能：

| 模块 | 功能 | 解决的问题 |
|---|---|---|
| **文风定位** | 一句话锁定江南味配方：文青小言的求不得 + 古龙短句 + 翻译体史诗语感 + 日漫镜头感 | 基调该往哪走 |
| **句式节奏** | 先铺陈后爆点、长短交替、段末短句盖章、招牌句法模板（平行世界句、二重反转句等） | 该怎么断句 |
| **叙述者声纹** | 4 声部稳定人格（克制旁观者 / 贫嘴插嘴 / 心疼补刀 / 点破宿命智者） | 判"像不像"的核心 |
| **意象系统** | 情绪→意象容器对照表（写孤独不写"孤独"，给孤独一个能摸到的物件） | 拿什么承载情绪 |
| **修辞技法** | 具象化抽象情绪、降维反差比喻、通感身体化、格言体插入 | 该怎么比喻 |
| **心理描写** | 贴身有限视角、名字锚点、"假设没有你的人生"招牌句法 | 怎么进人物的心 |
| **情绪工程** | 泪点三大机制（物件反转/时差迟到/平静绝望）+ 燃点防呆细则 | 燃点泪点怎么写 |
| **幽默方式** | 叙述者吐槽、人物自嘲贫嘴、冷面笑匠、ACG 梗 | 对话怎么好笑 |
| **快速校验** | 写完后过 7 条自检清单 | 防文青癌、防破功 |

**适用**：热血/致郁/物是人非/少年孤独质感的叙事、散文、同人、歌词式段落。
**不适用**：强情节、推理、谋略争霸类叙事（这是江南本人的短板，本 skill 不试图补齐——详见 5 诚实边界）。

## 3. 安装方法

本项目是一个 **WorkBuddy Skill**（写作风格引擎），通过把整个文件夹放入系统的 skills 目录完成"安装"。

### 方式 A：复制到用户级 Skills 目录（推荐，跨项目可用）

把整个 `jiangnan-writing-style/` 文件夹放到用户级 skills 根目录：

```
~/.workbuddy/skills/jiangnan-writing-style/
```

在 Windows 上，把 `<用户名>` 替换为你的实际用户名：

```
C:\Users\<用户名>\.workbuddy\skills\jiangnan-writing-style\
```

> 本项目目前已经安装在此位置。

若只想在某个特定项目内使用，放在该项目工作区的：

## 4. 使用方法

### 4.1 触发方式

在支持 Skill 加载的会话里，直接说这类话即可自动触发：

> 用江南的文笔写…… / 写成龙族那种感觉…… / 按江南的文风把这段重写…… / 九州那种苍凉味……

### 4.2 Skill 内置工作流（调用方无需记忆）

1. **定基调** → 判断落在燃点 / 泪点 / 日常幽默 / 史诗苍凉哪个位置，决定修辞密度与手段。
2. **选句式骨架** → 长句铺细节、短句做呼吸孔、段末短句盖章。
3. **种意象与情绪容器** → 写孤独别写"孤独"，给孤独一个能"亲手摸到"的容器。
4. **过"江南校验"** → 对照文末 7 条清单自检，防文青癌。

### 4.3 关键纪律（最容易破功的地方）

- **金句归叙述者，不归角色**：哲理总结放引号外；角色高光宣言只给短促口语。
- **哭留给读者**：让角色"翻一个玩具看底部"，不让角色嚎啕大哭。
- **修辞只在情绪最高点连发**：日常段白描，防止沦为"只有金句没有故事"。

## 5. 输入输出实例

> 以下两例为 Skill 指导下的**全新原创**输出（非江南原文），来自本地干跑测试（完整逐条自评见 `references/research/TEST-local-run.md`）。

### 实例一：泪点段（重访旧巷 · 物是人非）

**输入**
> 用江南的文笔写：主人公多年后回到童年老街，老街要拆迁，儿时爬墙偷枣的玩伴都各奔东西。突出"物是人非"。

**输出**
> 我沿着青石板一路走回去，走到巷子尽头那堵矮墙底下。墙比记忆里矮了一截，墙头那棵枣树的枝子垂下来，早没了当年挂满果子的样子，叶子蔫蔫的，落了一地，踩上去沙沙响，像谁在叹气。
>
> 我蹲下来，在墙根一丛草里扒拉。找着了——那年我们用刀在砖缝里刻的记号，三个并排的小人，底下歪歪扭扭写着"发大财"。刀痕被雨水冲得只剩下浅浅的印子，像要认不出了。
>
> 阿胖去了南方，猴子考去北京，就剩我一个还留在这座城里。可留在这座城里的我，跟那个踩着枣树翻墙的少年，又隔着多少年呢。
>
> 要是他们还在，这个点应该已经有人踩着树杈爬上来，笑嘻嘻地喊我接一把枣子。
>
> 风把落叶卷起来，扑了我一脸。我把那三个小人的印子又看了两眼，站起身，拍了拍膝盖上的土，没回头地走了。
>
> 老街要拆了。拆了也好——反正那个偷枣的少年，和他的一伙兄弟，早就不住在这里了。

### 实例二：燃点段（衰小孩为一个人挺身而出）

**输入**
> 用江南的文笔写：人人看不起的"废柴"男生，在雷雨天山路遇险时，为救一个曾对他好过的女生，做出生平最勇敢的决定。

**输出**
> 全班都知道陈默是个怂人。八百米跑倒数第一，拔河站最后面，别人欺负到他头上，他也只嘿嘿地笑，说没事没事。
>
> 那次春游返程遇上暴雨，大巴在半山腰抛了锚，半边山体轰地滑下来，车子被顶得往崖边一歪。一车人尖叫起来。
>
> 陈默缩在最后排，脸都白了。可他的眼睛死死盯着前面第三排——苏晓被行李压住，车窗外的泥浆正一寸寸漫上来，她在哭，在喊他："陈默！陈默！"
>
> 他该爬出车窗跑的。他腿软得站不起来。可那一声"陈默"，是他活这么大，第一次有人这么喊他，不带着笑，不带着嫌弃。
>
> 他忽然想起来，去年冬天的体育课，只有苏晓把她的外套递给他，说天冷，你穿上吧。
>
> "你他妈别怕。"陈默听见自己喊出这么一句——他这一辈子，没说过一句这么脏、这么响的话，"我来了！我来了！"
>
> 他连滚带爬地扑过去，泥水灌进嘴里，用背死死抵住那扇正被泥浆挤变形的车窗。轰的一声，整扇窗都被糊住了。
>
> 黑暗里，他听见自己心跳得像擂鼓，手抖得厉害，可他没松。
>
> 后来救援的人说，是那个平时最没用的男生，把全班人护在了身后。陈默自己知道，那不是勇敢。那只是一个被人喊了名字、被人递过一件外套的孩子，终于学会——为那一丁点暖，把自己豁出去。

### 本地开发与测试

- **目录结构**：见上文「安装后校验」。
- **干跑测试**：给一个输入场景，检查输出是否通过 `SKILL.md` 文末「快速校验」7 条清单（情绪有容器 / 段末短句盖章 / 金句归叙述者 / 悲伤身体化 / 有遗憾托底 / 修辞不滥 / 幼小视角）。
- **测试结论**：泪点段指令可执行性 A-、燃点段 B，整体 B+；能显著拉高文笔下限、避免廉价煽情。已知短板：燃点模块比泪点模块细则少，需写作者配合；"叙述者声纹"是判定像不像的核心，靠实践内化。

## 诚实边界

- 只覆盖**文笔层**，不提供"好故事的结构能力"（情节单薄、谋略弱等江南短板不在范围内）。
- 产出是**仿句式的新文字**，无法复刻江南本人的创造力与语料；引用原文必须核对正版纸书（部分流传名句出处含混）。
- 调研日期：2026-09-02，涉及近两年新作时建议补充调研。
