<br>

基于《龙族》×3、《九州缥缈录》×2、《此间的少年》×2、《上海堡垒》×1 共 8 段真实原文节选、

## 合规声明

> ✅ 非官方 / 非授权 / 非续作

- **非官方**：本项目是由爱好者基于公开文本与创作谈提炼的**写作风格研究工具**，与江南（杨治）先生及《龙族》《九州缥缈录》《此间的少年》《上海堡垒》的出品方、出版方**无任何隶属或合作关系**。
- **非授权**：本项目不代表任何权利方立场，不提供"官方结局"，不声称对原著情节或人物拥有解释权。
- **非续作**：不会以"正史/官方续写"的口吻补完或改写原著内容；仅用于生成**原创文字方案**与写作辅助（不冒充官方续作）。
- **不输出大段原文**：仓库中的 `references/research/` 目录仅收录少量用于技法研究的原文节选，对外分发内容**不包含**可替代正版书籍的长段逐字内容；如需引用请核对正版纸书。
- **仿写而非复制**：本 skill 的产出是"仿其句式、不抄其原句"的新文字，不会逐字输出江南作品原文。

## 效果示例

### 问：用江南的文笔写——路明非多年后回到仕兰中学的天台，发现那里要装新的信号塔。他想起高中时曾在这里给某个人打过一通没接通的电话。

```
江南文笔    ❯ 路明非踩着生锈的铁梯爬上去的时候，天台的风还是那么大。

              仕兰中学要翻新了，塔吊已经立在操场边上，连这个他以前
              偷偷躲上来抽烟的角落也不打算放过。他走到栏杆边，水泥台上
              还留着几道白粉笔的印子，是他当年无聊时画的——一个歪歪扭扭
              的S级，旁边一个更歪歪扭扭的笑脸。

              手机在兜里震了一下，他没看。

              很多年前的一个晚上，他也是站在这里，拨了一个号码。嘟嘟
              响了三声，然后是个温柔的女声说"您拨打的用户暂时无法接通"。
              他想说的话其实也不多，大概就是"我今天……"后面的内容他忘了，
              反正也没机会说完。

              风把他的头发吹得乱七八糟，像很多年前那个晚上一样。

              信号塔的工人已经开始在楼下焊接，火星子一明一灭。路明非
              从兜里掏出手机，对着那个他早就删掉的号码看了一会儿，又塞了
              回去。

              他说不上来自己为什么回来。

              只是有些东西，好像一直停在那个没拨通的电话里，等了很多年，
              也等不到一句"喂"。
```

### 问：用江南的文笔写——在卡塞尔学院的一次任务里，所有人都觉得路明非是个只会躲在最后的"S级水货"，可当龙类利爪要砸中诺诺时，他第一次没有逃。

```
江南文笔    ❯ 路明非这辈子跑过无数次。

              初中被堵在厕所时跑过，高中体育课跑八百米时跑过，来了
              卡塞尔学院之后，看见龙文闪红光时也跑过。他跑得不算快，
              但胜在起跑果断。

              所以没人相信他这次没跑。

              怪物从烟雾里冲出来的时候，恺撒正在换弹匣，楚子航的刀
              卡在龙鳞里拔不出来。诺诺背对着他们，无线电掉了，她没听见
              那一声吼。

              路明非听见了。

              他脑子里第一个念头和过去十八年一模一样：这他妈不关我的事。
              他的腿已经转过去了，就差一步就能扑到掩体后面。

              可诺诺上星期借给他的那盒泡面还在他柜子里，她当时说：
              "S级，请你吃，别饿死。"

              就这一句。

              他不知道自己是怎么扑出去的。记忆里有风声、有诺诺回头时
              睁大的眼睛、有他自己喊出来的一句脏话——不是言灵，不是
              战术，就是一句又短又脏的"操"。

              龙爪拍下来的瞬间，他撞在诺诺身上，两个人一起滚出去。

              整个世界都在震，他的背贴着碎石地，疼得眼前发黑。诺诺撑
              起来看他，路明非咧嘴笑了一下，说："学姐……你那盒泡面，
              我还没还你。"

              后来任务报告里写，是"S级学员路明非在关键时刻完成了救援"。

              路明非自己知道，那不是S级。那只是一个被人借过一盒泡面、
              喊过他名字的孩子，终于有一次——没跑。
```

> 完整的实战记录（执行路径 + 逐条自评）在 [`examples/`](examples/) 目录。

这不是"给 AI 塞了几本金句摘抄"。每段输出都在执行 SKILL.md 里可核验的技法：段末短句盖章、意象容器化情绪、金句归叙述者不归角色、角色悲伤身体化不嚎啕、差一步/迟到/不可逆托底。它不复读江南的原句，它用江南的**句式与情绪工程**重写你的素材。

## 蒸馏了什么

### 4 种叙述者声部（判定"像不像"的核心）

江南式文字能被认出，靠的是段落背后一个稳定人格的叙述者——一个曾是"衰小孩"的成年人。它按约 4:2:2:2 交替出场：

| 声部 | 职责 | 示例质感 |
|------|------|---------|
| **克制的旁观者**（主） | 黏在主角感官，只报看见/听见/感觉到 | 冷、准、稳，情绪交给动作与物件 |
| **贫嘴的插嘴者** | 对读者说话、假装严谨地修正自己的烂词 | 让前面的沉重透气 |
| **心疼的补刀者** | 情绪最高点"忍不住"替读者说出那句话 | 像心疼而非演讲 |
| **点破宿命的智者** | 一两句苍凉俯瞰收束 | "那些孩子都死了，只剩下……" |

### 4 大情绪基调

| 基调 | 触发场景 | 核心机制 |
|------|---------|---------|
| **燃点** | 少年高光、逆袭、为某人豁出去 | 先立怂的实据再翻、意志与身体打架、口号三连拍 |
| **泪点** | 告别、物是人非、晚到一步 | 物件反转、时差与迟到、平静的绝望短句 |
| **日常幽默** | 校园、对话、吐槽 | 叙述者吐槽体、角色自嘲贫嘴、ACG 梗 |
| **史诗/苍凉** | 九州式宏大宿命 | 短台词、史感动作、大留白、意象载一座城 |

### 8 类意象容器（拿什么承载情绪）

写孤独别写"孤独"——给孤独一个能摸到的容器：**落日车灯（孤独里的光）/ 雨夜屋檐（少年被围困）/ 玩具标签·日记一行字（最大的痛）/ 天台·夜班列车（慢性孤独）/ 上锁抽屉·旧花瓶（物是人非）/ 迟到的短信（可望不可即）/ 火与铁甲（誓约）/ 奔跑与列车（告别）**。同一批意象可在喜剧里先温情出场、高潮处"翻脸回收"成泪点。

### 防破功纪律（最容易破功的地方）

- **金句归叙述者，不归角色**：哲理总结放引号外；角色高光宣言只给短促口语（"我来了！我来了！"），不给工整对仗。
- **哭留给读者，不留给角色**：让角色"翻一个玩具看底部"，不让角色嚎啕大哭。
- **修辞只在情绪最高点连发**：日常段白描，防止沦为"只有金句没有故事"。
- **不抄原句、只仿句式**：产出是仿其句法的新文字；引用原文必须核对正版纸书。

### 内在矛盾（不是脸谱化的"伤感文豪"）

- **华丽 vs 油滑**：在"华丽但易感伤"与"自我重复/油腻"之间只有一线之隔，本 skill 默认站在克制一侧。
- **情绪 vs 情节**：江南被公认情绪大于情节（烂尾/自我重复）——本 skill 只做文笔层，不假装能补齐强情节能力。
- **畅销 vs 文学**：他自称"尽写些大家爱看的"（江八条），与评论界对"文学性"的期待存在张力，模仿时默认服务"好看"。

## 这个 Skill 是怎么造出来的

由 [女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill) 工作流蒸馏生成。

女娲的工作流程：输入一个作家名 → 多路并行调研（真实原文 / 创作自述 / 外部评价）→ 交叉验证提炼文笔 DNA → 构建 SKILL.md → 用真实输入场景做干跑验证并逐条自评。

想蒸馏其他作家？安装女娲：

```bash
npx skills add alchaincyf/nuwa-skill
```

然后说「蒸馏一个XXX的写作风格」就行了。
